# 高塔堆叠者 · 白盒

一个 3D 立方体（6 面 × 3×3 = 54 格）投影成球面的回合制计分游戏：每回合系统指定一个区域、掷 3 颗骰子，把数字填进该区域的空格并即时结算。6 个区域各轮到一次算一轮，3 轮共 18 回合后填满，比拼是否达到目标分。

白盒阶段只验证规则、数值与手感，不涉及美术表现。

## 运行

- Unity **2022.3.61f1c1**，内置渲染管线，旧版 Input Manager，uGUI
- 打开 `Assets/_Project/Scenes/Whitebox.unity`，点 Play

## 操作

| 操作 | 说明 |
| --- | --- |
| 拖左下角骰子 → 空格 | 落子（只能放金框内的当前区域） |
| 鼠标悬停空格 | 高亮并显示 `+N` 与来源（边同数 / 角异数 / 斜同数） |
| 按住左键拖球 | 旋转视角，不会误落子 |
| `R` | 重掷（每回合 1 次） |
| `空格` | 加速跳分与回合等待 |
| `F1` | 调试面板：种子、强制骰子、跳过回合、填满全盘、参数、导出 CSV |
| `N` | 2D 十字展开图（调试） |
| `Esc` | 取消拖拽 |

## 规则速记

- 边相邻（上下左右，跨棱也算）且数字相同：**+2**
- 角相邻（斜对角，跨顶点也算）且数字不同：**+1**
- 其余组合 0 分；每个邻居只按一种关系判定（顶点处双可达按「边」）
- 每 3 回合一次三选一，卡效果常驻，同名可叠加

```
├─ Tests/EditMode/   NUnit 单测（60 条）
└─ Editor/           批量模拟菜单（Tower/批量模拟 …）
```

## 测试与数据
